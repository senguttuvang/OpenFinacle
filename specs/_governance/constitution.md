# OpenFinacle constitution

1. Demonstrate an ordinary person's complete banking journey using synthetic data.
2. Apache Fineract is the financial source of truth. No simulated balance fallback.
3. Customer ownership and staff permissions are checked on the server.
4. A financial command has a stable identity. Ambiguous failures require reconciliation rather than blind retries.
5. Demo workspaces are isolated; identity verification and external payment networks are explicitly simulated.
6. Keep framework and provider details outside domain decisions. Tests verify lifecycle, ownership, failure, and financial effects.
