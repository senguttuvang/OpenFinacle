Architecture fitness: domain-independent and frontend-no-server-imports via dependency-cruiser; normal strict TypeScript/Biome/Oxlint/Knip/type coverage. Failure/empty/storage-recovery states are part of the route. No external resource or provider changes.

Portal integration contract: extract the existing planning route into one reusable workspace, dynamically mounted within the existing portal shell. The embedded mode preserves a single main landmark and portal heading, uses server persistence only, and inherits the existing persona/reading-size controls. The authenticated router delegates only the exact planning namespace after its existing session guard. Migration0015 appends planning tables/triggers without rewriting bank records. The protected release restore verifier accepts pre-planning exports, requires the complete planning pair and trigger group when present, and keeps existing repayment and strict SQL-bail guards. Finacle4 remains the sole merge/migration/deployment owner.
