# OpenFinacle

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Customers managing their banking, and branch officers and independent approvers handling the same relationship. Older customers need comfortably readable screens.

## Product Purpose

Reconstruct customer internet banking and branch workflows in a working demonstration with persistent, synthetic data. Specifications under `specs/006-reference-banking-experience/` own capability requirements and evidence boundaries.

## Capabilities and Constraints

Fineract owns balances and financial postings. Explicit simulated products and workflow records persist separately. Preserve maker-checker, uncertainty, review, idempotency, recovery, and role boundaries. Do not fabricate charts, financial performance, or completed capabilities. Never include real banking information. The repository remains private.

## Brand Commitments

OpenFinacle. The user requests a colorful, modern, professional interface with Xero and Payoneer as public visual references. Retain clear banking terminology and recognizable controls.

## Accessibility & Inclusion

Comfortable large text by default. The user removed the separate extra-large text button on18October2026; retain browser zoom and enlarged-text reflow support. Generous controls, strong contrast, keyboard operation, responsive reflow, and readable financial values take priority over decorative density.
